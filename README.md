# Smart Agriculture Monitoring System 🌱

An IoT-based smart agriculture system designed to assist farmers through real-time soil monitoring, crop disease detection, and intelligent fertilizer/pesticide recommendations.

## 🚀 Features

- Real-time soil moisture monitoring
- NPK (Nitrogen, Phosphorus, Potassium) analysis
- Crop disease detection using uploaded plant images
- Fertilizer recommendation system
- Pesticide recommendation system
- Web-based monitoring dashboard
- IoT sensor integration

---

## 🛠️ Technologies Used

### Hardware
- Soil Moisture Sensor
- NPK Sensor
- Microcontroller (ESP32/Arduino)

### Software
- Python
- JavaScript
- Node.js
- HTML/CSS
- Machine Learning
- Image Processing

---

## 📷 Crop Disease Detection

Users can upload crop images through the web platform.  
The system analyzes the images to identify potential plant diseases and provides suitable treatment recommendations.

---

## 🌾 Soil Analysis

The system continuously collects:
- Soil moisture levels
- Nitrogen values
- Phosphorus values
- Potassium values

Based on the collected data, the platform recommends:
- Suitable fertilizers
- Required pesticides
- Crop health insights

---

## 📊 System Workflow

1. Sensors collect soil data
2. Data is transmitted to the web platform
3. User uploads crop image
4. Disease detection model analyzes the image
5. System generates recommendations
6. Results displayed on dashboard

---

## 💡 Objective

The project aims to support smart farming practices by helping farmers make data-driven decisions for improved crop health and productivity.
